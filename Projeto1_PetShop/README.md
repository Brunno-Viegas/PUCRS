# Ajuda - PetShop Bub's

Projeto da disciplina de Fundamentos de Sistemas Web (PUCRS) - Fase 1
Autor: Brunno da Silva Viegas

## Sobre o site

O PetShop Bub's é um site feito apenas com HTML que apresenta os produtos e serviços de um petshop. Nesta fase não foram usados CSS, Bootstrap nem JavaScript.

Site publicado: https://brunno-viegas.github.io/PUCRS/Projeto1_PetShop/
Código-fonte: https://github.com/brunno-viegas/PUCRS/tree/main/Projeto1_PetShop

## Páginas do site

- Página inicial (index.html): mensagem de boas-vindas, descrição do petshop e atalhos para as categorias de produtos e para os serviços.
- Produtos (produtos.html): três categorias (Alimentação, Higiene e Acessórios), com dois produtos em cada uma. Cada produto tem imagem, nome, descrição e valor.
- Serviços (servicos.html): lista de serviços (Banho e Tosa, Consulta Veterinária e Hospedagem), com descrição, valor e se tem tele-busca ou não.

## Funcionalidades

1. Menu de navegação: aparece no topo e no rodapé de todas as páginas e leva para Início, Produtos e Serviços.
2. Atalhos por seção: na página inicial, os links levam direto para uma categoria de produtos ou para um serviço específico.
3. Índice no topo de Produtos e Serviços: permite ir direto para a categoria ou serviço desejado, sem rolar a página.
4. Consulta de produtos: o cliente vê foto, descrição e preço de cada item.
5. Consulta de serviços: o cliente vê o que cada serviço inclui, o preço e se o petshop faz a busca do animal em casa (tele-busca).
6. Rodapé: traz endereço, telefone, e-mail, autoria e direitos autorais.

## Como usar

1. Acesse o link do site publicado.
2. Use o menu do topo para escolher a página.
3. Em Produtos, clique na categoria desejada no índice ou role a página.
4. Em Serviços, confira o valor e se o serviço tem tele-busca.
5. Para voltar à página inicial, clique em "Início" no menu.
